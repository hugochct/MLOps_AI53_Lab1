## Milestone 1

**Engineering checkpoint 1:**

- **`pyproject.toml`**: The project’s main configuration file. It describes the Python project, its dependencies, supported Python versions, and tool settings.

- **`uv.lock`**: A lock file generated by **uv**. It records the exact versions of all installed dependencies, including indirect dependencies, so everyone can recreate the same environment reliably.

- **`.venv/`**: The project’s local Python virtual environment. It contains the selected Python interpreter and installed packages, isolated from other projects and from the system Python installation.

## Milestone 2

**Engineering checkpoint 3:**

- Git remote: Stores the project’s source code, configuration files, documentation, and Git-tracked metadata such as .dvc files.

- DVC remote: Stores the actual versioned data files and other DVC-managed artifacts, such as the raw images.

- Does git push transfer the DVC-managed raw images ? No, git push transfers only Git commits and metadata; the images require a separate dvc push.
